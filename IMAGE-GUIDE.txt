COOKIE WOOKIE — IMAGE FILE GUIDE
==================================
Every image the site uses lives in ONE folder: assets/photos/
To swap in real photography, replace a file below with your own photo
SAVED UNDER THE EXACT SAME FILE NAME — every page that uses it updates
automatically. Don't rename files, don't add new ones for existing
products; just overwrite.

(assets/logo.svg, assets/favicon.svg and assets/divider.svg are small
brand graphics, not photos — no need to touch these.)

Recommended format: JPG, landscape/square as noted below, at least the
pixel size listed (larger is fine, the site scales images down).
